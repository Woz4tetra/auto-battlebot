MOTOR HEAT

The stall guard's thermal model. Above 35 C it folds the drive back until 50 C, where it holds each motor at its continuous current. Amber sensors mean one source is missing and the guard is running on the other.

WIFI

CLIENT MODE DISABLED: ESP-NOW IS ON

This build has ESP-NOW enabled, so the robot always runs its own access point () on the ESP-NOW channel (). Joining a router would move the radio to the router's channel and cut the dongle off. Saved networks are kept and take effect in a build with ESPNOW_ENABLED = false.

MODE ON BOOT

SAVED NETWORKS

    TUNING

    ESC deadzones and yaw loop gains. A change applies at once and saves to flash while disarmed; one made while armed saves at the next disarm.

    ESC SETTINGS BLHeli_32 over the signal wires

    Bench only, props off. Tuning mode stops both motors and hands the ESC signal wires to the BLHeli bootloader. It is refused while armed, and the robot cannot drive inside it; the radio button or EXIT leaves it. The first read of each ESC downloads a backup, and so does every write.

    ARMED WHILE TUNING

    The ESCs cannot drive in tuning mode. Exit it to drive.

    Amber rows differ between left and right; → and ← copy one value across. An outlined cell is edited and not yet written. Nothing reaches an ESC until APPLY and WRITE.

    LAST REBOOT

    A crash or a loop() pass over 5 s (task watchdog) saves a core dump to flash and reboots. Decode it over USB with scripts/coredump, or the backtrace with addr2line against the same build's firmware.elf. Erase it once read so the next one is not mistaken for it.

    ESP-NOW

    ALLOWED DONGLES

    The robot only accepts paired dongles. Pairs are saved on the robot and survive reboots and reflashes. Pair a new dongle by plugging it in near the robot and pressing ALLOW on it below. Disarm first.
