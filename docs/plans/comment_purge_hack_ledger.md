## How to read it

- **Verified?** starts with `yes:`, `no:`, or `unverified:`. Auditors read code paths and installed
  library sources. They did not build C++, run the app, flash firmware, or touch hardware, so most
  `unverified` rows need one of those to settle.
- 124 rows are verified, 10 failed verification, 186 are unverified, and 2 carry no tag. 83 rows
  have no known root-cause fix.
- By area: `training/` 76, `firmware/` 39, `src/` 31, `tests/` 30, `hardware/` 27, `scripts/` +
  `install/` + `service/` + `web/` + `CMakeLists.txt` + `mypy.ini` + `docker/` 59, `playground/` +
  `simulation/` + `logo/` 31, `auto_battlebot/` 16, `include/` 13.

## Repeated workarounds

One root-cause fix retires several rows each.

- **ESP32 platform pin.** `espressif32@6.13.0` in `firmware/mr_stabs_mk2/platformio.ini:15`,
  `firmware/espnow_dongle/platformio.ini:8`, and the 250-byte frame limit in
  `espnow_protocol.h:22`, plus `DShot.cpp:8` writing into NeoPixel's private
  `rmt_reserved_channels[]`. Fix: port DShot to the IDF 5 `rmt_tx` driver.
- **libnvjpeg symbol clash.** `CMakeLists.txt:281-284` and `:321-324`,
  `include/viz/nvjpg_jpeg_encoder.hpp:12`, `src/viz/nvjpg_plugin/nvjpg_plugin.cpp:1`. The dlopen
  plugin is the fix; the rows need a guarding test, not removal.
- **Eigen `FromTwoVectors` `-Wmaybe-uninitialized` on GCC 13.** Four sites:
  `front_back_keypoint_converter.cpp:111`, `point_cloud_field_filter.cpp:337`,
  `field_pose.cpp:301`, `foxglove_adapters/scene.cpp:82`. Fix: one `rotation_between()` helper.
- **ZED SDK 5.2 quirks.** `src/rgbd_camera/zed_one_rgb_camera.cpp` has five, including the
  setting nudge at `:394` and `_Exit` on a wedged `grab()` at `:51`. Most may go with an SDK upgrade.
- **BlenderProc segmentation pass indices.** Defended at 6 sites in `training/synthetic/synthgen/`
  (`pipeline.py`, `distractors.py`, `damage_scene.py`, `cage_scene.py`). Fix: one helper that sets
  the pass index as each object is created. Also 9 scripts carry the "blenderproc must be the first
  import" line.
- **ESP DTR/RTS reset.** Copied three times (`espnow_diag.py:924`, `espnow_ota.py:255`,
  `usb_dashboard.py:46`), and `usb_dashboard.py` does it differently. Fix: one shared helper.
- **Camera retry and cancel.** `src/runner.cpp:521-523` drains commands after the retry sleep
  because every camera's `initialize()` clears `cancel_open_`. Fix: stop clearing it there.
- **`sys.path` routes around the package rule.** `install/install_python_environment.sh:215-224`
  writes an `auto_battlebot.pth` and `mypy.ini:11-16` sets `mypy_path` for `logo/` and
  `training/synthetic/`; `tests/python/test_gpu_queue.py:1` loads `training/gpu_queue.py` by path.
  Fix: move the shared modules into `auto_battlebot/`.

## Bugs found during the audit

These are defects in code, not workarounds. None were fixed.

- `scripts/run_simulation.sh:27-29`: both branches assign the same config path, so the fallback to
  the shared base config never happens.
- `firmware/velocity_jig/scripts/console.py:21-22` and `firmware/velocity_jig/README.md:82-83` use
  0.070 dps and 0.000244 g per LSB. `include/config.h` is now 0.140 and 0.000488 (±4000 dps,
  ±16 g), so the console live stream reads 2x low.
- `src/field_filter/point_cloud_field_filter.cpp:296`: the comment says the normal is flipped to
  -Z, but the code produces z >= 0 while the fallback at `:290` returns (0, 0, -1). The audit
  marked it `TEST` to pin the intended sign.
- `include/tensorrt_inference/trt_engine.hpp:23-31`: `ScopedQuietLogging` demotes TensorRT errors
  through a global counter, so it hides real errors on other threads during engine probing.
- `training/yolo/convert_to_tensorrt.py:187-195`: `preprocess_frame` defaults `letterbox_padding`
  to 0.0 while `TrtYoloModel` and the deployed engines use 0.1. INT8 calibration passes it
  explicitly; any other caller gets the wrong padding.
- `hardware/cage_pack/camera_boot.py`: dead. It reads `cl.BOOT_WALL` and `enclosure.boot_holes()`,
  which no longer exist, and nothing imports it.
- `CMakeLists.txt:441`: the ZED debug-build override also sets `-Wno-extra -Wno-error` on 7 of our
  own sources, against the "fix warnings, don't suppress them" rule.
- Docs referenced but missing: `docs/robot_filter_decay_plan.md` (cited at
  `tests/test_robot_front_back_filter.cpp:302,371`), `docs/velocity_jig_wiring.md` (the file is
  `firmware/velocity_jig/velocity_jig_wiring.md`), and `docs/hardware/README.md`.
